# Controles

Todos reasignables en Ajustes → Controles (con «Restaurar controles predeterminados»).
Los ajustes y las teclas persisten en el navegador (localStorage).

| Acción | Predeterminado |
| --- | --- |
| Mover | W / A / S / D |
| Mirar | Ratón |
| Atacar | Clic izquierdo |
| Concentrar apuntado (−10° FOV, −50 % dispersión, 75 % velocidad) | Clic derecho |
| Caminar silencioso | Shift |
| Agacharse | Ctrl |
| Saltar | Espacio |
| Recargar | R |
| Habilidad propia | Q |
| Granada de niebla | G |
| Interactuar / instalar / desactivar | E (mantener) |
| Soltar núcleo | F |
| Compra (en preparación; libre en entrenamiento) | B |
| Marcador | Tab (mantener) |
| Seleccionar ataque principal | 1 |
| Menú de pausa y liberar ratón | Esc |
| Giro con teclado (apoyo) | Flechas |
| Overlay de desarrollo (FPS, ping, tick, draw calls) | F3 |
| Overlay de hitbox de cabeza (depuración) | F4 |

Notas:
- La pérdida de foco de la ventana limpia todas las entradas (no quedan disparos ni movimiento
  atascados).
- Al morir: clic para alternar el aliado observado.
- Accesibilidad: «movimiento reducido» (menos sacudidas/efectos) y «destello accesible»
  (oscurecer en lugar de pantalla blanca) en Ajustes.
